# v1.8.15 — Momentum Watch + Stock Chart Improvements

Changes:
- Stock detail chart is constrained to the available screen width and remains responsive on desktop/mobile.
- Selected chart range is preserved in the stock URL when switching/redrawing.
- Momentum Watch uses the top 10 funds per selected category.
- Fund Flow now exposes all tracked outcomes: increased, decreased, unchanged, new and sold/exited.
- Momentum Watch shows the latest holdings disclosure date when the source publishes one.
- Allocation delta continues to include exits at 0% so a sale cannot be hidden by a changing current-holder denominator.
- Deep-correction disclaimer updated to use a documented 2025 Morgan Stanley/Counterpoint Global base-rate study rather than the unsupported claim that exactly half of stocks never recover after a 50% fall.
