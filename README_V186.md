# v1.8.16 – Fund-by-fund allocation details

Momentum Stock Watch now includes an expandable **Fund details** control in each stock row. It shows every fund in the selected Small Cap or Mid Cap universe, current allocation, previous allocation where available, and a plain-language outcome (Increased, Decreased, No change, New, Sold / exited, or Not held / no prior holding data).

This makes a 3/5 holding count and the Fund Flow column fully auditable instead of leaving the user to infer what happened to the remaining funds.
