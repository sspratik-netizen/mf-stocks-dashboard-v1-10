How sector shareholding is calculated

The page groups the current Nifty 500 universe by the industry/sector field supplied with the NSE constituent data. The sector percentages are the equal-weighted average of the available stock-level shareholding percentages for the selected quarter. A missing stakeholder value is not replaced with a guessed value.

Ten quarterly observations are shown when the underlying filings provide them. This is an analytical aggregation, not an official NSE sector index.

Default order: decreasing YoY Sales Growth. Published Results uses stocks with a filing in the current reporting period.

How sector results are calculated

Stock-level NSE results are aggregated across the selected sector. Quarterly values are summed for the sector; YoY compares the same reporting period one year earlier. Annual values use completed fiscal-year quarters available from the underlying filings. EBITDA is calculated only when the required operating-profit, interest and depreciation fields are available; otherwise it is shown as unavailable rather than estimated.

Stocks Published Results is the default view and uses stocks that have reported in the current period. Entire Sector uses all stocks for which the corresponding period data is available.

Corporate data: NSE India public corporate filings. Universe: current Nifty 500 constituent list.
